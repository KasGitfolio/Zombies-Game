This was part of a university project, we were given a set of requirements that the game needed and many programming techniques to increase our grade. Using java (processing IDE), I created a game that the protagonist moves based on the mouse cursor and the enemies move towards. The game gets harder as it progresses and the user is given a set number of lives that can be viewed from the hearts indicator on the top left of the screen. It features a menu, saved high scores, main part of game, animated characters, and an option to restart when the game ends. 
This project achieved me 78%.
